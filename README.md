# Dexbot

Assistente inteligente em desenvolvimento.

## Interface

A interface web usa HTML, CSS e JavaScript puro e pode ser publicada pelo GitHub Pages.

## Estado atual

- Interface inicial de conversa.
- Envio de mensagens na tela.
- Seleção e pré-visualização de imagens.
- Conexão com o mecanismo de IA ainda pendente.

O GitHub Pages hospeda apenas a interface estática. Para responder perguntas e interpretar imagens, será necessário conectar um backend e um modelo de IA.
